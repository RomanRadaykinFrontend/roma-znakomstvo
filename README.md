# Знакомство с Ромой 🔥

Тиндер, но лучше: один кандидат — ноль конкуренции.

## Как заменить фото

Положи файл `roma.jpg` рядом с `index.html` и запушь в `main` — фото появится само.

## Как поменять имя / возраст / описание / телеграм

Всё в блоке `CONFIG` в начале `<script>` в `index.html` (телеграм — поле `tg`).

## Приколы

- Свайп влево не работает (первый раз — просто не работает)
- Второй свайп влево — «ВЫ ВСЁ РАВНО ЛАЙКНУЛИ РОМУ»
- Кнопка «нет» уворачивается от нажатий
- Чат с Ромой — он отвечает на всё
- Тапни 5 раз по фото 👀
- Лайкнул 5 раз подряд — Рома смущается
